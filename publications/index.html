Current Research

My current research addresses how hardware faults affect AI and scientific software, and how compression and hardware acceleration improve scientific data workflows.

LLM Inference and Adaptation Reliability

I characterize how transient hardware faults affect LLM inference, including models adapted to new tasks. I evaluate response reliability and protection costs to guide more dependable execution.

Compiler and Runtime Resilience

I develop and evaluate software approaches to detecting silent data corruption in scientific and HPC applications, balancing detection effectiveness with execution overhead across different workloads.

GPU Scientific Compression

I design GPU compression software for scientific data and evaluate compression throughput, data fidelity, and the cost of moving compressed data through scientific workflows.

FPGA Compression and Reusable Hardware

I develop FPGA compression hardware and reusable design components, balancing processing throughput, memory traffic, hardware resources, and implementation flexibility.
