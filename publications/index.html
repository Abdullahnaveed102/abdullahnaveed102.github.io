Publications

Peer-reviewed and accepted work in dependable AI, high-performance storage, and software security.

  1. SC’26
    Low-Overhead Silent Error Detection for Large Language Model Inference at Scale

    Abdullah Naveed, Mahina Sheikh, and Guanpeng Li

    [SC’26] International Conference for High Performance Computing, Networking, Storage, and Analysis · Accepted; to appear

    Introduces TRACE, a selective activation-monitoring framework that detects silent data corruption across 15 large language models with 95.3% average coverage and only 0.56% runtime overhead.

  2. SC’26
    Z-SPDK: Accelerating Lossy Compressed I/O on NVMe-SSDs

    Darren Ng, Abdullah Naveed, Duo Zhang, Guanpeng Li, Sheng Di, and Xiaoyi Lu

    [SC’26] International Conference for High Performance Computing, Networking, Storage, and Analysis · Accepted; to appear

    Co-designs lossy compression and NVMe I/O using dual-pipeline parallelism and zero-copy transfers, delivering up to 12× speedup and 5.9× better bandwidth utilization.

  3. SecDev’23
    Evaluating Container Debloaters

    Muhammad Hassan, Talha Tahir, Muhammad Farrukh, Abdullah Naveed, Anas Naeem, Fareed Zaffar, Fahad Shaon, Ashish Gehani, and Sazzadur Rahaman

    [SecDev’23] 2023 IEEE Secure Development Conference

    Introduces DebloatBenchC and evaluates container debloating tools across attack-surface reduction, CVE mitigation, image-size reduction, and execution correctness.
