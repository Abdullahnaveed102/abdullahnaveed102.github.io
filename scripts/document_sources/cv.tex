\section{Research Experience}

\begin{cvitems}

  \item Developed \textbf{TRACE}, a runtime silent-error detector achieving \textbf{95.3\% average detection coverage} across 15 LLMs and 3 datasets with \textbf{0.56\% runtime overhead}; paper accepted at SC26.
